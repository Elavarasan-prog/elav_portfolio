## 🚀 Core Specializations & Technologies

- **Business Intelligence & Dashboards**: Power BI Desktop, DAX, Power Query, Data Modeling, Star Schema, Slicers & Drill-throughs
- **Visual Analytics**: Tableau Desktop, Calculated Fields, Dual-Axis Charts, Parameters, Heatmaps, Geospatial Mapping
- **Database & Querying**: SQL (SELECT, WHERE, GROUP BY, ORDER BY, Multi-table JOINs, Subqueries, CTEs, CASE Statements, Window Functions)
- **Spreadsheet Modeling & ETL**: Microsoft Excel (Pivot Tables, XLOOKUP, VLOOKUP, INDEX & MATCH, SUMIFS, COUNTIFS, Data Cleaning)
- **Methodology**: End-to-end analytics lifecycle (`Collect → Clean → Analyze → Visualize → Communicate`)

---

## 🌟 Featured Project: Zomato Data Analysis

A comprehensive analytics project analyzing restaurant and food-service data to uncover consumer preferences, pricing elasticity, location-based performance, and rating drivers across Bangalore.

- **Excel Analysis**: Cleaning noisy strings, deduplication, formula-based normalization, and exploratory pivot tables.
- **SQL Analytics**: Multi-condition CTEs, window functions ranking localities, and CASE statement price tier aggregations.
- **Power BI Dashboard**: Interactive rating tier slicers, dynamic DAX measures for unrated outlets, and online delivery ratios.
- **Tableau Dashboard**: Geospatial restaurant density heatmaps, cuisine share breakdowns, and price-to-rating correlations.
- **Interactive 6-Step Case Study**: Built directly into the website (`Dataset → Cleaning → Transformation → Analysis → Dashboard Development → Insights`).

## 🛠️ Portfolio Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with dark theme (`#0B1120`), glassmorphism, and neon glowing accents
- **Motion & Visuals**: Framer Motion, Three.js / Canvas interactive node network, Recharts, Lucide React
- **Typography**: Inter (UI) and Fira Code (Technical Data Queries)

## 💻 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/Elavarasan-prog/elav_portfolio.git

# 2. Navigate to project folder
cd elav_portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open ([https://elavportfolio.vercel.app/)] in your browser to view the portfolio.
